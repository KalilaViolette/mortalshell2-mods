# MortalShell2TTS curated pronunciation defaults
# Pass 124 / v0.9.201 - pronunciation subsystem remains frozen; active rule data unchanged from Pass 84
#
# Format: match | spoken-as | scope [| unsupported-voice-fallback]
# These are the ACTIVE shipped defaults. The LocalAppData file is only an override layer.
# TAB-separated match<TAB>spoken-as<TAB>scope<TAB>fallback lines are also accepted.
# Scope: azure | local | all
#
# Matching is case-insensitive and only replaces a whole word or whole phrase.
# "spoken-as" can be either a plain alias or, for Azure-only rules, ipa:<phones>.
# IPA rules may add an optional fourth field: fallback:<plain spelling>. The helper
# uses IPA only for voice families that support <phoneme>; unsupported/unknown voices
# automatically receive the fallback spelling instead. Plain aliases remain useful
# for simple compounds and names. These defaults are intentionally Azure-scoped because
# the initial report was against Azure/MAI
# narration. Windows local voices remain unchanged unless a user adds an "all"
# or "local" override in:
#   %LOCALAPPDATA%\MortalShell2TTS\PronunciationCorrections.txt
#
# User overrides are persistent and win over shipped defaults by match text.
# Use spoken-as !disable in the user file to disable a shipped default.
# The helper notices edits and reloads this small dictionary before the next
# synthesis request; no game restart or settings UI is required.
#
